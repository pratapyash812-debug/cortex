# Cortex 1.3.6

Built on 1.3.5 and its preloaded writing page. The new controls follow the existing notebook, subject, and page layout.

## Writing shortcuts

Use Ctrl+Alt on Windows or Cmd+Alt on Mac with the listed key.

1. **0** applies Normal paragraph.
2. **1** applies Heading 1.
3. **2** applies Heading 2.
4. **3** applies Heading 3.
5. **4** applies Heading 4.
6. **5** applies Heading 5.
7. **6** applies Heading 6.
8. **7** toggles a numbered list. List controls now keep the caret in the list during rapid typing.
9. **8** toggles a bulleted list.
10. **9** toggles a checklist.
11. **H** toggles highlighting.
12. **S** toggles strikethrough.
13. **L** aligns left.
14. **E** centers text.
15. **R** aligns right.
16. **J** justifies text.
17. **Q** toggles a quotation.
18. **Backspace** clears inline styling.
19. **Left arrow** decreases indent.
20. **Right arrow** increases indent.
21. **Page → Keyboard shortcuts** opens the full list inside Cortex.
22. Formatting button tooltips show their corresponding shortcuts.

## Formatting

23. The main font control follows the caret or selection.
24. The main size control shows the current text size.
25. The main colour control shows the current text colour.
26. The paragraph picker shows the current heading, body style, or quotation.
27. Emphasis buttons show active and mixed styles.
28. List buttons show the current bullet, numbered, or checklist state.
29. Alignment buttons show the current or mixed alignment.
30. Undo and Redo indicate when there is an edit available.
31. Undo and Redo can be used from inside code blocks.

## Find

32. A distant match scrolls into view below the sticky formatting and Find bars.
33. Find starts with the selected text when the selection is short and on one line.
34. Press Ctrl/Cmd+F again to return to Find and select the query.
35. Match case can distinguish words such as GDP and gdp.
36. Whole word distinguishes terms such as cost from costs.
37. Ctrl/Cmd+G advances to the next match while Find has focus.
38. Ctrl/Cmd+Shift+G returns to the previous match while Find has focus.
39. The Find button exposes whether its panel is open.

## Pages and subjects

40. The page filter is available in small subjects as well as large ones.
41. Page filtering accepts several words across the title and its chapter path.
42. Pages can be sorted by title, with Exercise 2 before Exercise 10.
43. Pages can be sorted by last edit.
44. The pin button filters the current subject to pinned pages.
45. The page count shows how many pages are visible when filtered.
46. The empty results state offers Reset filters.
47. Arrow keys, Home, and End move between page rows.
48. The document footer shows your page position and lets you step forward or back. Ctrl/Cmd+Shift+Page Up or Page Down does the same.
49. Switching back to a subject returns to your last page in it during the current session.
50. Note search results appear independently of PDF search, so a slow or unavailable PDF index no longer holds up matching notes.
